# Trente ateliers pédagogiques — Et si l’IA

Ces ateliers accompagnent la passe détaillée des deux premiers lots d’articles. **Toutes les entrées sont fictives**, construites pour expliquer un calcul. Aucun résultat de ces dossiers ne mesure les performances d’un service réel.

Chaque dossier contient le programme complet, les entrées, les résultats effectivement calculés, un manifeste et un README. Python 3.10 ou plus, bibliothèque standard uniquement. Pas de clé API ni de téléchargement de modèle.

```sh
cd panier-courses
python3 demo.py
```

Régression linéaire, recherche lexicale TF-IDF, distance standardisée, K-means, régression logistique, classification de couleurs et spectrogramme sont des briques pédagogiques. Les limites de chaque brique figurent dans les articles. La recherche lexicale n’est pas un encodeur sémantique ; le spectrogramme n’identifie aucune espèce ; la distance standardisée n’est pas une forêt d’isolation.

Les expériences sur données publiques déjà évaluées restent dans les dossiers historiques à la racine du dépôt. Ne pas remplacer leurs scores par ceux des exercices fictifs.
