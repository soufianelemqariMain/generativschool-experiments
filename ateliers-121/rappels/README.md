# Atelier : rappels

Données entièrement fictives. Ce petit calcul explique une brique ; il ne démontre pas le fonctionnement du service prospectif. Python 3.10 ou plus, sans installation de bibliothèque et sans clé API.

```sh
python3 demo.py
```

Ouvrir `demo-input.json` pour voir et modifier les entrées. `demo-results.json` contient le résultat calculé. Conserver une copie du résultat initial pour comparer.

Algorithme : TF-IDF lexical, pas un encodeur sémantique.
