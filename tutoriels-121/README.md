# Trente tutoriels progressifs — Et si l’IA

Ces programmes accompagnent les trente enquêtes en préparation. Chaque dossier contient le code Python, les entrées fictives définies dans ce code, les sorties exécutées, le tutoriel et une scène SVG en calques.

**Ces exemples pédagogiques ne remplacent pas les expériences sur données publiques présentes ailleurs dans le dépôt.** Les opérations qui ne sont pas des modèles appris sont désignées comme filtres, références ou calculs. Aucun résultat réel supplémentaire n’est revendiqué.

Python 3.10 ou plus, bibliothèque standard uniquement :

```sh
cd panier-courses
python3 demo.py
```

Le README de chaque dossier explique l’unité, l’opération, une modification à essayer et ce qui manque pour passer aux données réelles. Les sorties attendues sont dans `sorties.txt`. Les scènes JSON et SVG sont produites à partir de l’état calculé, pour réutilisation ultérieure dans les vidéos ; aucune vidéo n’est produite ici.
